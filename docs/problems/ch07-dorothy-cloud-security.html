Chapter 7

Dorothy Gale Secures the Emerald City Cloud

Dorothy Gale, Cloud Architect at Emerald City Solutions, has just inherited a sprawling AWS environment built rapidly during the company's pandemic-era growth. The footprint includes managed Kubernetes clusters running customer workloads, a fleet of Lambda functions stitched together by API Gateway, an S3 bucket holding eight years of customer data, and a half-dozen SaaS apps that the marketing team adopted without telling IT.

Last quarter brought two scares. First, a security researcher demonstrated that a misconfigured Lambda IAM role had read access to the customer S3 bucket — and the function had a server-side request forgery flaw that an attacker could have exploited to pivot. (The Capital One breach had used a strikingly similar pattern.) Second, an external auditor flagged that the bucket was "public" — though it later turned out only the bucket policy was misread; objects inside had no public ACLs. Either way, the auditor was unimpressed.

Dorothy now has board backing to tighten things up. Her plan covers responsibility boundaries, container and serverless hardening, API protections, governance of shadow SaaS, customer-managed encryption, and a layered control strategy that includes detective and preventative components — not just preventative.

External Cloud Audit — Emerald City Solutions, engagement EC-Q3

Auditor: Glinda Northrop, OSCP/OSCE. Findings 1–6 of 6. Distribution: CISO, Cloud Architect, Board Audit Committee.

[HIGH] F-1. Lambda function customer-search-v3 holds s3:GetObject on * — not scoped to the /customer/ prefix — and the /lookup endpoint exposes a confirmed SSRF vector. The pre-conditions for a Capital-One-shaped exfiltration are present.

[HIGH] F-2. EKS cluster prod-east-1 enforces no admission-time image policy. Pods are running with node-level IAM credentials rather than per-pod workload identities.

[HIGH] F-3. API Gateway in front of the Lambda fleet authenticates clients with a static API key in the URL query string. No per-client throttling or quota configured.

[MED] F-4. Customer bucket cust-data-prod is encrypted with the default AWS-managed KMS key. The enterprise contract signed 2026-04 with Munchkin Industries stipulates keys that AWS cannot read.

[MED] F-5. The Marketing team has onboarded four SaaS apps (Asana, Calendly, Loom, Notion) without IT registration. Customer data has already flowed into at least two of these tenants.

[INFO] F-6. Bucket public-exposure regression reported by internal auditor on 2026-08-14 — on review, object ACLs were never actually public (bucket-policy misread). No continuous configuration-drift detection is in place; the next check is the annual external audit.
