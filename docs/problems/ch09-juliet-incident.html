Chapter 9

Juliet Reviews the Imaging-Department Ransomware (Diagnostic)

Six months after Verona Health's BYOD program went live, the headline numbers are good: 3,800 personal devices enrolled in containerized management, conditional access blocking non-compliant devices at the managed-app sign-in, FIDO2 rolled out for the EHR mobile app. The CISO stopped flinching when the board asked about phones.

Then, on a Sunday night, every workstation in the radiology department encrypts itself. The ransom note names Verona Health. The imaging archive — including studies mid-read — is down. Elective procedures are cancelled for nine days.

The investigation finds two doors. The first was a BYOD door nobody thought was still open. The second was the legacy enclave the program had explicitly fenced off — fenced off correctly, then quietly un-fenced by someone trying to be helpful.

Post-incident report — radiology ransomware, INC-2026-309.   Author: J. Capulet, Awareness & BYOD lead. Status: draft for board, OCR breach counsel, and the imaging vendor. Do not forward.

Reconstructed chain

  • Day −9 A radiologist signs into the EHR through the vendor web portal in a personal phone browser, not the managed containerized app. The portal was never placed behind conditional access — only the managed app was. Credentials phished two weeks earlier are replayed successfully. FIDO2 is enforced on the managed app; the web portal still accepts a password.
  • Day −9 → −2 Attacker uses the EHR foothold to reach the clinical network and stage tooling.
  • Day −2 A biomedical-engineering vendor technician, doing scheduled calibration on the Windows 7 MRI workstation, unplugs it from the isolated enclave VLAN and patches it into a general clinical wall port 'to pull a calibration file faster.' No request, no approval, no rollback note. The box is now flat with the clinical network.
  • Day −1 Attacker reaches the now-reachable MRI workstation. It has no EDR (Windows 7, unsupported). The attacker extracts NTLM hashes and Kerberos tickets from LSASS memory and moves laterally to the imaging file servers.
  • Day 0 Ransomware detonates across radiology.
  • Day 0 → +3 IR cannot produce an authoritative list of imaging-adjacent hosts; the CMDB was last reconciled 16 months ago. Scoping is done by walking the floor.

Contributing failures

  • Conditional access and FIDO2 were enforced on the managed app only. The EHR vendor web portal — reachable from any browser — was never brought under either control.
  • The Windows 7 enclave's protection was network isolation. A vendor tech defeated it with a patch cable and no change process.
  • The unsupported host had no behavioral endpoint protection; the credential theft from memory went unseen.
  • IR could not scope the blast radius because the asset inventory was not current.
