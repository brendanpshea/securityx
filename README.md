# SecurityX: An Open Textbook for the CompTIA SecurityX (CAS-005) Exam

**SecurityX** is an open-access textbook and practice-problem collection that prepares readers for the CompTIA SecurityX (CAS-005) certification exam. It is freely available for both self-study and classroom adoption.

**Read the book online:** <https://brendanpshea.github.io/securityx/>

---

## About the Book

The CAS-005 exam covers a broad sweep of senior-level cybersecurity practice — governance and risk, secure architecture, identity, cryptography, network and endpoint engineering, specialized and OT systems, and security operations. Most existing study materials are either narrow exam-cram products or expensive proprietary textbooks. This project aims to be a third option: a thorough, pedagogically structured, openly licensed text that also works as a course textbook.

Each of the twelve chapters follows a consistent structure:

- **Learning outcomes** mapped to Bloom's taxonomy
- **Core narrative content** organized around guiding questions
- **Fictional case studies** featuring a recurring cast of characters drawn from literature and folklore (Snow White as a GRC analyst, Fitzwilliam Darcy as a risk director, Count Dracula as a CISO, etc.) — chosen to make scenarios memorable without trivializing the material
- **Historical case studies** of real-world breaches (Target, SolarWinds, Capital One, Equifax, DigiNotar, Log4Shell, and others)
- **Diagrams and tables** generated reproducibly from Python scripts
- **Review questions** and answer keys
- **Interactive scenario problems** (one per chapter) where readers practice applying chapter concepts in cloze-style decision-making exercises

## Status

All 12 chapter sources and all 12 interactive scenario problems are present in the repository and published to the site. Current work is focused on revision, factual QA, source documentation, and production polish rather than initial chapter creation.

## Audience

- **Students** preparing for the CAS-005 exam, including those who have already passed Security+ and CySA+ and are looking for a coherent next step.
- **Instructors** teaching senior-level cybersecurity courses who want a license-friendly text they can adapt, excerpt, or remix for their own offerings.
- **Practitioners** who want a structured refresher on the modern CASP+/SecurityX domain.

## Repository Structure

```
src/chapters/        Markdown source for each chapter
src/scripts/         Build scripts for HTML pages and figures
refs.bib             Shared bibliography for static chapter citations
problems/            JSON source files for interactive practice problems
docs/                Generated static site (published via GitHub Pages)
docs/chapters/       Rendered chapter HTML
docs/problems/       Rendered interactive problems
docs/assets/         CSS, JS, and figure assets
table_of_contents.md Detailed chapter outlines and learning outcomes
exam_objectives_tracking.md  Mapping of CAS-005 objectives to chapter coverage
```

## Building Locally

The site is generated by two Python scripts. With Python 3.10+, the `markdown` package installed, and **Pandoc** available on your `PATH`:

```bash
# Render chapter HTML from markdown with static citations from refs.bib
python src/scripts/build.py

# Render interactive problem pages from JSON
python src/scripts/build_problems.py

# (Optional) Regenerate chapter figures
python src/scripts/generate_figures_ch1.py
# ... and similarly for other chapters
```

Outputs are written to `docs/`, which is served directly by GitHub Pages.

## Citations

Chapter citations use Pandoc citation syntax directly in the markdown source, for example:

```md
[@nist-ai-rmf-2023]
[@nist-sp800-53r5-2020; @fedramp-authorization-designations-2026]
```

During `python src/scripts/build.py`, Pandoc `citeproc` resolves those keys against `refs.bib` and emits plain HTML citations and bibliography entries. No client-side JavaScript is required, which keeps the output compatible with static publishing environments such as GitHub Pages and Pressbooks.

## AI Use Disclosure

This textbook was developed in close collaboration with **Anthropic's Claude (primarily Opus 4.7)**. The author drafted the chapter outlines, learning outcomes, pedagogical approach, character cast, and case-study selections; Claude was used to produce initial chapter prose to those specifications. All AI-generated content was then **substantially revised, fact-checked, restructured, and edited by the human author** before publication. Diagrams were produced with Python (matplotlib / graphviz) using AI-assisted scripts that were then human-tuned for clarity.

## Contributing

- **Errata** — typos, factual errors, broken links, outdated references
